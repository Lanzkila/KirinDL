# Bio Kirin v2 — GitHub Pages Preview

This is an isolated conversion test of the **Bio-Kirin v2 Bento Grid** theme from the `Lanzkila/Template-Blogger` repository.

- Source: `Template/Bio Kirin/Bio-Kirin v2.xml`
- Preview route after a Pages build: `/KirinDL/bio-kirin-preview/`
- Blogger-only wrappers (`b:skin`, `b:section`) were removed.
- The original CSS and JavaScript were retained as static assets.
- XML-style self-closing HTML tags were normalized for HTML5.
- The profile content, external links, AniList feed, and iCount visitor widget remain as they were in the source for this visual/functional trial.

This folder is a test only. The main KirinDL homepage and existing Support, Contact, and Privacy pages are not replaced by this preview.

The preview-test workflow builds the whole Jekyll site and uploads a temporary artifact only; it does not publish or deploy the preview. Its content checks target the actual IDs and selectors used by this template.
