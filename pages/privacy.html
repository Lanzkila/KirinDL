PRIVACY

A clear note on privacy.

KirinDL is an open-source Android application. This page explains the basic scope of this project website and where to review the app implementation.

THE APPLICATION

App data and downloads

Downloads, preferences and local app data are handled on the device according to the application source code and the services a user chooses to access.

For implementation details, review the public KirinDL source code ↗.

THIS WEBSITE

Project website

The site requests public repository and release statistics from the GitHub API. The homepage may store these counts locally for up to one hour to reduce repeat requests. It does not require an account to browse.

This is an independent KirinDL site and does not use SealPlus sponsor data, the sealplus.in domain or archived SealPlus website assets.
