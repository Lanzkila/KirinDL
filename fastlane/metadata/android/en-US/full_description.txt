KirinDownloader is an open-source media and gallery downloader for Android.

Features include:
• Media downloads powered by yt-dlp
• Gallery downloads powered by gallery-dl
• Gallery batch queue and history
• Download format and output controls
• Optional cookies and advanced configuration
• KirinDownloader visual identity with adaptive and themed icons

KirinDownloader does not request Android package-install permission for self-updates. Update checks
open the official GitHub release page so installation remains an explicit user action outside the
app.

This project is based on open-source software. Upstream projects and licenses remain credited in
the app.
