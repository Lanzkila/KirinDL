Tujuan:
- Merancang semula halaman GitHub Pages KirinDL.
- Reka bentuk keseluruhan yang dicadangkan: susun atur berasaskan card.
- Catatan ini bersifat sementara untuk mengumpulkan keputusan sebelum rombakan sebenar dimulakan.

PART 1 — SPLASH SCREEN LOGO

Keperluan:
1. Apabila pelawat membuka website, paparkan splash screen dengan logo KirinDL.
2. Splash screen muncul semasa halaman sedang dimuatkan.
3. Selepas halaman utama selesai dimuatkan, splash screen hilang secara automatik dengan animasi fade-out.
4. Pelawat tidak perlu menekan butang untuk menutup splash screen.
5. Splash screen hanya untuk kemasukan awal ke website dan tidak muncul semula setiap kali pengguna bertukar bahagian atau navigasi dalaman.

PART 2 — HOME PAGE / HEADER

Keperluan:
1. Home page mempunyai hamburger menu.
2. Hamburger menu dipaparkan sebagai fungsi "Coming Soon" buat masa ini.
3. Sediakan hero card untuk profil repository.
4. Hero card memaparkan logo repository, nama author dan pautan ke repository.

PART 3 — BODY / REPOSITORY DETAILS

Keperluan:
1. Di bahagian body, sediakan satu tab/section statistik repository.
2. Tab statistik memaparkan jumlah Star, Fork dan Download.
3. Di bawah tab statistik, paparkan koleksi card.
4. Card boleh dislide secara mendatar ke kiri dan kanan.
5. Sediakan anak panah navigasi kiri dan kanan ("<" dan ">") untuk mengawal slide card.
