# KirinDL v3.2.4

Prepared · 16 November 2026

This release consolidates the v3.2.3.1 update-workflow changes and the follow-up v3.2.3.2, v3.2.3.3 and v3.2.3.4 improvements into one v3.2.4 release record. Each change below links to its implementation commit and identifies the version in which it was introduced.

## v3.2.3.1 — Update Popup and Workflow Baseline

The following changes describe the earlier v3.2.3.1 state. The automatic checker was disabled in that release and was restored in the subsequent v3.2.3.2 work; the two additional update popups remain disabled in v3.2.4.

- Temporarily disable the Morphe Home update alert while preserving its implementation for possible reactivation. - Temporarily disable the standalone startup update popup and preserve its original implementation in the source as comments. ## Compatibility Notes

- Instaloader preview is limited to public profiles. It does not log in or reuse GalleryDL cookies; private profiles, Stories and Highlights are not included. ([7ef868d](https://github.com/Lanzkila/KirinDL/commit/7ef868d53afe98659a117982b5f03361569c1236)) | (v3.2.3.3)
- Telegram preview supports public channels and public post links only; private/invite-only channels and authenticated history are not included. ([770bcff](https://github.com/Lanzkila/KirinDL/commit/770bcff1cda7563a41c64179f0c76a22ccc59915)) | (v3.2.3.4)
- Telegram's public web preview exposes a limited rolling window; pagination can request older posts using the message-ID cursor only while those posts remain available through the public preview. ([1c3f375](https://github.com/Lanzkila/KirinDL/commit/1c3f375c5771e5556161ef479003119917fc7d7e)) | (v3.2.3.4)
- Telegram media can only be downloaded when the public web preview exposes a direct, supported Telegram CDN URL. ([02fd61e](https://github.com/Lanzkila/KirinDL/commit/02fd61e9bcb040801663241ec3586684adad1c46)) | (v3.2.3.4)
- The Telegram engine APIs are in place, but a dedicated Telegram screen and Home routing are not yet connected. ([770bcff](https://github.com/Lanzkila/KirinDL/commit/770bcff1cda7563a41c64179f0c76a22ccc59915)) | (v3.2.3.4)
- No Telegram login, API hash, phone number, password or session data is collected or stored. ([770bcff](https://github.com/Lanzkila/KirinDL/commit/770bcff1cda7563a41c64179f0c76a22ccc59915)) | (v3.2.3.4)
- GalleryDL downloads continue to use the existing GalleryDL engine; Telegram uses its separate adapter. ([770bcff](https://github.com/Lanzkila/KirinDL/commit/770bcff1cda7563a41c64179f0c76a22ccc59915)) | (v3.2.3.4)
