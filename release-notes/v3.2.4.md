# KirinDL v3.2.4

Prepared · 16 November 2026

## App Update

- Restore the built-in automatic update checker through the existing **About → App Update** preference.
- Allow the original automatic update preference to control startup update checks again.

## Gallery DL Improvements

- Show the full large gallery preview image without cropping while preserving the existing 16:9 preview area.
- Keep the small thumbnail in the Extractor Inspector unchanged.
- Add persistent last-expanded dropdown state for **Video Tools** and **Gallery Tools** in More Tools.
- Restore the previously expanded category when returning from a tool or reopening More Tools.
- Opening one category closes the other; tapping the currently open category collapses it.

## Instagram Profile Preview

- Add a dedicated KirinDL Instaloader adapter under `app/src/main/python/kirindl_instaloader/`.
- Detect HTTPS Instagram profile links submitted from Home and route them to Gallery DL.
- Preview up to 36 recent posts from public profiles.
- Add post selection controls for **Select shown**, **Clear**, and **Queue selected**.
- Send selected canonical post links to the existing GalleryDL queue; GalleryDL remains responsible for downloading the media.
- Fall back to normal GalleryDL extractor inspection when Instaloader preview is unavailable.
- Separate Instagram preview models into `InstagramPreviewModels.kt`, keeping the bridge focused on Python communication.

- Special thanks to [@thirteenth13](https://github.com/thirteenth13) for sharing the fork and providing the inspiration for this Instaloader integration.

## Telegram Engine Foundation

- Add a dedicated Telegram module under `app/src/main/python/kirindl_telegram/` and Kotlin APIs under `com.junkfood.seal.util.telegram`.
- Add strict parsing for public Telegram channel and post URLs.
- Add bounded public channel/post preview through Telegram's `t.me/s/` web preview, with pagination support.
- Extract available post text, date, view count and direct media metadata.
- Add media selection helpers and selected-media download support.
- Restrict downloads to direct media URLs hosted on Telegram CDN domains and enforce a 2 GB per-file limit.
- Save downloaded media under the app-specific `Downloads/KirinDL/Telegram` directory.
- Add unit tests for Telegram URL parsing and media selection.

## Compatibility Notes

- Instaloader preview is public-profile only. It does not log in or reuse GalleryDL cookies. Private profiles, Stories and Highlights are not included.
- Telegram preview currently supports public channels and public post links only. Private/invite-only channels and authenticated history are not included.
- Telegram media can only be downloaded when the public web preview exposes a direct, supported Telegram CDN URL.
- The Telegram engine APIs are in place, but a dedicated Telegram screen and Home routing are not yet connected.
- No Telegram credentials or session data are collected or stored.
- The existing GalleryDL engine is still required for GalleryDL downloads; Telegram uses its separate adapter.
