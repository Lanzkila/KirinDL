# KirinDL v3.1.7

### Fix New Update popup and About update recovery

KirinDL v3.1.7 fixes the New Update popup flow and improves the App Update section inside About.

## ✦ Updates

- Fixed the **New Update** popup trigger when a newer KirinDL release is available
- Removed the old behavior that could prevent the same update popup from appearing again after it had already been shown once
- Added a safer automatic update-check flow when KirinDL enters the main app interface
- Added an automatic-check cooldown to avoid unnecessary repeated GitHub release requests
- Added **About → App Update** as a manual recovery path when the automatic popup was dismissed or missed
- About can now perform a fresh manual update check and reopen the same New Update popup
- Improved the About update card status for checking, up-to-date, offline, retry, and update-available states
- Improved the New Update popup version display with clearer **Installed → Available** information
- Added clearer **Stable / Pre-Release** identification
- Fixed Pre-Release version text so its full version suffix is preserved
- Improved long release-note scrolling inside the update popup
- Kept background APK update download support when a compatible release asset is available

## ✦ About Update Recovery

If the automatic New Update popup is dismissed or missed, open:

```text
Settings
→ About
→ App Update
```

KirinDL will perform a fresh update check and reopen the update popup when a newer release is available.
