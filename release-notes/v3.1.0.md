# KirinDL v3.1.0

### First official KirinDL release — Media • Gallery • Batch

KirinDL v3.1.0 is the first official release under the **KirinDL** identity.

## ✦ Highlights

- Full visible rebrand to **KirinDL**
- Signed **Universal Release APK**
- Dedicated **Gallery DL Hub**
- Unified **Engine Update Center**
- yt-dlp **Stable / Nightly** update channels
- gallery-dl updates from **Codeberg master**
- Gallery batch queue and persistent history
- Theme-aware Gallery interface
- Stable debug signing and private release signing
- GitHub-based KirinDL application update checks

## ✦ Engine Update Center

Both yt-dlp and gallery-dl can now be checked and updated from one screen.

## ✦ Gallery DL Hub

Includes single URL downloading, batch queue, persistent queue/history, extractor checks, config import/export, optional cookies, cache, and organized Gallery output.

## ✦ Universal APK

```text
KirinDL-Universal-Release.apk
```

Supported native targets:

- arm64-v8a
- armeabi-v7a
- x86
- x86_64

## ✦ Verification

Official releases include:

```text
KirinDL-Universal-Release.apk
KirinDL-Universal-Release.apk.sha256
```

## ✦ Open Source Credits

KirinDL builds on Seal, SealPlus, yt-dlp, youtubedl-android, gallery-dl, FFmpeg, aria2, and other open-source work used by the app.
