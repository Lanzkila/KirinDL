# KirinDL v3.1.8

### Download stability, engine status, and build fixes

KirinDL v3.1.8 includes the download configuration fixes already prepared for this release, plus the final stability fixes validated through the latest pre-release builds.

## ✦ Fixes

- Fixed Kotlin string interpolation and escape sequences in the download configuration UI.
- Fixed unresolved references in `ActionSheet.kt` related to codec, container, and Bilibili configuration values that are not available in the current preferences model.
- Fixed the audio/video format summary section so its types and format fields are resolved correctly.
- Fixed the download configuration summary display for media mode, format information, engine, and fragment count.
- Restored the download task/state handling to the known-good devpatch11 implementation after later devpatch changes caused downloads to stop running correctly.
- Restored the matching download status UI behavior so task state, progress controls, and download actions stay aligned with the working devpatch11 source.
- Fixed the Engine Update Center showing `Installed: Unknown` for yt-dlp on a fresh install. KirinDL now reads the bundled yt-dlp runtime version after engine initialization and stores the real installed version immediately.
- Updated the project version to **3.1.8** and synchronized the Android `versionCode`.

## ✦ Stability validation

- The final pre-release build completed signing, package identity checks, checksum generation, and APK verification successfully.
- The tested final pre-release no longer showed the previous Android install-block warning seen during the affected devpatch testing.

## ✦ Build and release pipeline

- Improved Kirin Pre-Release publishing by using the proven GitHub release action path.
- Pre-release builds can now be started either manually from GitHub Actions or through the repository trigger path used for connector-assisted testing.
- Universal and ARM64 APKs continue to be signed and verified before publishing.
