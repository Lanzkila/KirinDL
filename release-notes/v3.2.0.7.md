# KirinDL v3.2.0.7

### Pre-release — YouTube download recovery

## YouTube fixes

- Add automatic recovery when YouTube returns “Sign in to confirm you’re not a bot”, a playback-client error, HTTP 403, or unavailable format data.
- Apply recovery to video/playlist info, comments, and audio/video downloads.
- Retry with compatible playback clients while preserving the selected quality, audio/video format, subtitle settings and download options.
- When a saved session still causes bot verification, allow one temporary guest attempt for a single video. Saved cookie profiles and the Use Cookies setting are retained.
- Bound recovery to two attempts, or three for a single video with saved cookies. Cancellation stops pending retries; private playlists, age restrictions and rate limits do not trigger guest recovery.
- Keep the original YouTube error and show cookie-login guidance when YouTube still refuses access.

## Cookie fixes

- Import `#HttpOnly_` Netscape cookie rows correctly, including exports containing only HttpOnly login cookies.
- Preserve HttpOnly markers, host-only domains, session expiry and empty cookie values when generating cookies.txt.
- Use YouTube’s cookie domain for short-link, mobile and embedded-player profiles.
- Include the previous atomic cookie-file refresh fix in this APK.
