# KirinDL v3.2.3.4

Prepared · 16 November 2026

## Instaloader Code Organization

- Separate Instagram preview data models into `InstagramPreviewModels.kt`.
- Keep the Instaloader bridge focused on Python communication.

## Telegram Engine

- Add an isolated Telegram module with URL parsing, public channel/post preview, pagination, media selection helpers, and selected-media downloads.
- Read public posts through Telegram's `t.me/s/` web preview without requiring Telegram sign-in.
- Restrict downloadable media URLs to Telegram CDN hostnames and enforce a 2 GB per-file limit.
- Save downloaded media under the app-specific `Downloads/KirinDL/Telegram` directory.

## Compatibility Notes

- Telegram preview currently supports public channels and public post links only.
- Private/invite-only channels, authenticated history, and media not exposed as direct Telegram CDN URLs are not included.
- Telegram preview and download APIs are implemented as a separate engine; a dedicated Telegram screen and Home routing are not yet connected.
- No Telegram credentials or session data are collected or stored.
