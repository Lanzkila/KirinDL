# KirinDL v3.2.0

### Gallery DL collections, Bilibili restore, and UI polish

KirinDL v3.2.0 is a larger Stable feature release focused on Gallery DL collection workflows, cleaner UI, Media progress presentation, expanded yt-dlp controls, and restoring the dedicated Bilibili download profile.

## ✦ Gallery DL

- Added a persistent **Expert Config ON/OFF** toggle. When disabled, KirinDL does not apply the custom raw gallery-dl JSON to checks or downloads.
- Moved **Media Export Filter** into a compact popup menu instead of showing all filter choices directly on the settings page.
- Reworked the **Gallery DL theme selector** into a compact rounded popup with a two-column theme grid.
- Each theme now uses a short name, short description, color preview, and selected-state indicator.
- Simplified the Gallery DL engine source label to **Codeberg master** instead of displaying a raw commit hash.
- Added collection detection to Gallery DL preflight.
- Collection links now expose a dedicated **Download All** mode.
- The main action changes automatically from **Download Gallery** to **Download All** when the source is a collection.
- Queue action changes to **Queue All** for collections.
- Confirmation dialogs clearly indicate when every child item from a collection will be followed.
- Large collections no longer use a partial preflight scan count as if it were the final total; indeterminate progress is used until an exact count is known.

## ✦ Hentai manga collection sources

Added dedicated recognition for hentai-manga collection links while leaving normal/non-hentai websites on the existing generic flow.

Supported collection types include:

- Artist
- Publisher
- Group / Circle
- Magazine
- Series / Parody
- Character
- Tag
- Language
- Category / Genre

Recognized hentai-manga collection links are routed directly through **Gallery DL** instead of unnecessarily trying yt-dlp first.

Gallery metadata handling was expanded to read additional creator/source fields such as publisher, group, circle, magazine, series, and parody when an extractor provides them.

## ✦ yt-dlp Audio settings

- Unlocked the yt-dlp **Audio** configuration section so audio format, bitrate, codec, cover, and conversion settings can be edited even when the global **Extract audio** switch is off.
- **Extract audio** now acts as the default download mode instead of locking the Audio preset controls.

## ✦ Media card progress

- Changed Media transfer status badges to use whole-number percentages.
- Removed decimal progress such as `42.0%`.
- Active phase badges now use the compact KirinYT-style format:

  - `Video : 42%`
  - `Audio : 68%`
  - `Fragment : 73%`
  - `Processing : 81%`
  - `Merge : 94%`
  - `Paused : 55%`

- The existing temporary/cache path remains displayed beneath active and paused Media cards.

## ✦ Bilibili

Restored the dedicated Bilibili download profile that had previously been removed while isolating an unrelated pre-release download failure.

Restored support includes:

- Bilibili-specific URL detection
- `bilibili.com`
- `bilibili.tv`
- `b23.tv` short links
- **Auto / Balanced / Fast / Custom** Bilibili speed modes
- Dedicated concurrent-fragment tuning
- Bilibili-specific Aria2 connection cap
- Additional retry handling for fluctuating Bilibili/CDN routes
- Bilibili-specific socket timeout tuning
- Adaptive Auto mode using the previous successful Bilibili average download speed
- Direct routing of `b23.tv` links into the Bilibili video flow

Other websites continue using the normal global fragment and Aria2 settings.
