# KirinDL v3.1.9

### Global Feed, Gallery DL, Kirin Search, and Media progress update

KirinDL v3.1.9 consolidates the Global Feed, Gallery DL, Kirin Search, Download Center, and Media card improvements prepared after v3.1.8, with the latest thumbnail and transfer-progress fixes included.

## ✦ Global Feed & Kirin Search

- Added page navigation to **Global Feed** source contents so larger channels, playlists, collections, feeds, and other supported sources can be browsed page by page.
- Added page navigation to **Kirin Search** results.
- Moved Global Feed search into the top app bar beside **Add Source**.
- Removed the duplicate **Add Source** button from the Global Feed information card.
- Restyled Global Feed source counts as compact count badges.
- Added an explicit **Play** action to Media results in Kirin Search and Global Feed.
- Fixed queue-only Gallery DL sources that returned valid feed entries but did not provide thumbnails for every rendered card.
- Global Feed now probes thumbnails for all **24 preview cards** instead of stopping after the first 12.
- Added automatic detection of the old 12-thumbnail cache pattern so affected Global Feed sources refresh and rebuild their preview cache instead of continuing to show blank images.

## ✦ Media transfer progress

- Restored live transfer progress in the unified Download Center for active Media downloads.
- Added progress directly to **every Media queue/card layout**, including compact and full cards.
- Media cards now show the current percentage and a live progress bar when progress is available.
- Added phase-aware status labels for **Preparing**, **Video**, **Audio**, **Fragment**, **Merge**, **Processing**, and **Paused** states.
- Media card progress is connected to the existing live `Task.DownloadState` instead of using a separate download implementation.
- These progress changes remain UI/display-layer changes; DownloaderV2, Task execution, DownloadUtil, retry logic, and the yt-dlp runtime are not replaced.

## ✦ Gallery DL

- Added a large Gallery DL image preview below the **Paste / Check** controls when the extractor returns a thumbnail.
- Kept the existing extractor information and validation flow intact.
- Improved unified Download Center integration for Gallery DL queue and history records.
- Fixed **Clear Completed** so it clears completed Media history, completed Gallery DL queue entries, and successful Gallery DL history together.
- Failed Gallery DL history is preserved.
- Pending, running, paused, and failed Gallery queue entries are preserved.
- **Clear Completed** does not delete downloaded files; it only removes completed activity/history records.
- Updated the confirmation text to clearly describe both Media and Gallery cleanup.

## ✦ Download Center

- Improved the unified Media + Gallery DL activity view.
- Active Media entries now expose their live transfer state, percentage, progress text, and phase directly in the Download Center.
- Queue, paused, failed, and completed states remain separated so cleanup actions do not remove unfinished work.

## ✦ Stability & verification

- The dedicated KirinDL Stable Test completed successfully with the current v3.1.9 candidate changes.
- The Stable Test passed APK build, release signing preparation, package verification, Universal APK preparation, and artifact upload.
- Stable publishing has been restored to the normal **GitHub Releases** flow after artifact-only testing.
- Stable release assets remain the signed **Universal APK**, **ARM64 APK**, and their SHA-256 checksum files.
