# KirinDL v3.2.0.1

### App updater hotfix and cleaner release notes

KirinDL v3.2.0.1 is a hotfix revision for the new v3.2.0 release. It focuses on making the in-app updater follow the installed version correctly, improving the release-note popup, and continuing app installation after Android Download Manager finishes.

> **Fallback:** If this hotfix causes a device-specific issue, you can temporarily return to **KirinDL v3.2.0** or the older **v3.1.9.1** Stable release.

## ✦ Bilibili rollback

- Removed the dedicated Bilibili transfer profile introduced in v3.2.0 after it caused slower behavior on some devices.
- Removed Bilibili-specific Auto / Balanced / Fast / Custom fragment tuning.
- Removed the Bilibili-only Aria2 cap, timeout, retry override, and adaptive previous-speed logic.
- Removed the unused Bilibili speed controls from Seal Plus Extras.
- Removed the special `b23.tv` direct-video routing that was added with the profile.
- Bilibili remains supported through the normal yt-dlp flow, while the existing Bilibili search/discovery support is kept.

## ✦ App update checker

- Automatic update checks now reset their cooldown immediately when Android installs a different KirinDL version.
- The newly installed APK becomes the updater baseline as soon as the app starts.
- Automatic checks now run on a shorter daily cooldown instead of inheriting the previous build's stale check time.
- Switching between Stable and Pre-release channels clears the old channel check time so the newly selected channel can be checked immediately.
- The installed version shown in the update UI is read from the currently installed package.
- Stable revision versions such as `3.2.0.1` are now parsed and compared correctly instead of being treated as `3.2.0`.
- Pre-release ordering is kept below Stable releases for the same major/minor/patch version.

## ✦ Download Manager → Install update

- In-app updates continue to use Android Download Manager.
- KirinDL remembers the Download Manager job used for the app update.
- When the APK download completes, KirinDL hands the APK to Android's package installer.
- If Android requires **Install unknown apps** permission, KirinDL opens the system permission screen first and continues the installer flow after permission is granted.
- A completed update also posts an **Update ready** notification as a fallback on Android versions that block background activity launches.
- Installing a release signed with the same KirinDL release key updates/overwrites the existing app instead of creating a second installation.
- Android still shows the final system installation confirmation; KirinDL does not silently confirm package installation.

## ✦ Release notes popup

- Cleaned up duplicate version headings from GitHub release notes.
- Added proper spacing between headings, paragraphs and list items.
- Added better nested-list indentation.
- Markdown blockquotes such as stability/fallback notes now render as a distinct highlighted note.
- Code blocks use a dedicated monospace container.
- Four-part Stable versions are shown correctly in the popup.
- Updated the popup wording to explain the Download Manager → Package Installer flow more clearly.

## ✦ Manual update checks

- Manual **Check for updates** now uses the same Download Manager/install flow as the automatic update popup when a downloadable APK is available.
- The App Update page no longer directs normal APK updates to the browser when the official Universal APK is attached to the release.
