# KirinDL v3.1.3

### Search polish • safer updates • better themes • Download Center refinement

KirinDL v3.1.3 focuses on polishing the v3.1.2 feature set, tightening update-channel behavior, improving theme consistency, and making Search and Download Center easier to use across phones and larger screens.

## ✦ Highlights

- Refined **Kirin Search** with a cleaner compact search field
- Improved **YT Music Songs only** filtering for Topic, original/official audio, and song-style results
- Reworked **App body color** and **Buttons & accent color** pickers with visual color cards
- Added more **Gallery DL color variants**
- Improved **Light Theme** styling and contrast
- Download Center now follows the selected theme more consistently
- Added clearer dividers and option grouping in Download Center
- Improved Active / Queue / Failed / Done metric responsiveness
- Separated **Stable** and **Pre-release** update channels more strictly
- Improved app-update popup behavior so the same release does not repeatedly appear
- Changed user-facing Search download actions from **Configure** to **Download**
- Improved temporary cookie handling and cleanup for both download engines
- Added better extractor-removal / unsupported-site detection for yt-dlp and gallery-dl

## ✦ Search & YT Music

Kirin Search now uses a cleaner search field with simpler wording while keeping keyboard Search behavior. YT Music's Songs only mode has been tightened so obvious music videos, live performances, lyric videos, covers, karaoke, Shorts, teasers, trailers, and similar non-song results are filtered more aggressively.

Songs only now prioritizes Topic channels, original/official audio, original/official song results, and metadata that clearly identifies a song or audio result.

## ✦ Download Center

Download Center now follows the active KirinDL color theme more consistently, including custom accent presets. Option groups have clearer dividers so controls remain visible even when using non-default themes.

The Active, Queue, Failed, and Done cards have been polished for smaller phones and larger displays, with improved wrapping and themed container colors.

Gallery DL remains available from Home rather than being mixed into the main Download Center view.

## ✦ Look & Feel

The App body color and Buttons & accent color dialogs now use cleaner visual color cards with live previews and selected-state indicators instead of the older plain choice list.

Light Theme has also been refined with softer surfaces, better separation between cards and background, and improved contrast while still following the selected KirinDL accent colors.

Additional Gallery DL theme variants include Sakura Pink, Crimson, Amber Gold, Teal, Indigo, and Lime alongside the existing Follow app, Kirin Cyan, Ocean Blue, Emerald, and Violet presets.

## ✦ Update Channels

Stable and Pre-release channels are now handled separately:

- **Stable** checks stable KirinDL GitHub releases only
- **Pre-release** checks KirinDL prerelease / DevPatch releases only

The automatic update popup remembers the last release it already showed, reducing repeated popups for the same version. Version display in the popup is also cleaner, using a simple Installed → Available format.

## ✦ Engine Reliability

Temporary cookies used by yt-dlp and gallery-dl tasks are copied into task-specific temporary locations and cleaned up after success, failure, or cancellation. Persistent user cookie files are left untouched.

KirinDL also keeps better track of extractor availability so a site whose extractor was removed or disabled upstream can be reported more clearly instead of appearing as a generic retry failure.

## ✦ Download Flow Polish

User-facing actions in Kirin Search now use **Download** instead of **Configure** where the action continues into the normal pre-download settings flow. The underlying configuration flow remains intact.

## ✦ Release Preparation

- Version: `3.1.3`
- Package ID remains `com.kirin.downloader`
- Universal APK target remains unchanged
- Stable release workflow: `.github/workflows/android.yml`

## ✦ Verification
