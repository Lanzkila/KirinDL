# KirinDL v3.2.2

Prepared · 12 November 2026

## Startup Update Popup

- Add a standalone update check and popup when KirinDL enters the main app after splash and onboarding.
- Respect the existing **Auto Update** preference and automatic-check interval.
- Restore a cached available update when a fresh network check fails.
- Remember dismissed update tags so the same release does not interrupt every app launch.
- Allow a newer release to appear even after an older release was dismissed.
- Keep **About → App Update** unchanged as an independent manual update entry point.

## Update behavior

- Use the existing update dialog and background-download path when a compatible universal APK asset is available.
- Keep the startup popup implementation separate from the About and App Update pages.

## Bilibili Download Completion

- Prevent network auto-pause from cancelling an active yt-dlp task after it has entered FFmpeg merge or local post-processing.
- Allow merge and post-processing to finish using the streams already downloaded, instead of restarting the transfer because of a temporary network interruption.
- Keep normal active transfers and retry states eligible for the existing network-pause behavior.
- Add regression coverage for merge/post-processing stage detection and network-pause eligibility.
