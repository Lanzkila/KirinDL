# KirinDL v3.1.2

### Search, Sources & Unified Download Center

KirinDL v3.1.2 focuses on a cleaner Home experience, unified download activity, discovery tools, Saved Sources, and reliability polish without changing the core downloader architecture.

## ✦ Highlights

- Added **Unified Download Center** for Media + Gallery activity
- Added **Kirin Search** for YouTube, YouTube Music and Bilibili
- Added **Saved Sources** for supported channels, playlists and collections
- Added YT Music **Songs only** mode focused on Topic/original/official song-style results
- Improved Search caching, cancellation and Configure navigation reliability
- Added responsive width polish for phone, tablet and desktop layouts

## ✦ Home & Download Center

- Removed Recent Downloads cards from Home so Home stays focused on starting downloads
- Download icon now opens the Unified Download Center
- Added All / Media / Gallery views and Active / Queue / Paused / Failed / Completed filters
- Added Search, sort, Retry Failed and Clear Completed history controls
- Clear Completed removes history only and keeps downloaded files

## ✦ Kirin Search

- Search YouTube video, YouTube Music and Bilibili media
- Configure, Queue, Open Source, Copy Link and Details actions
- Multi-select with Queue Selected
- Recent and favourite searches
- YT Music Songs only filtering
- Relevance / Latest / Views sorting
- Search-state persistence, lightweight cache and stale-request protection

## ✦ Saved Sources

- Supports YouTube channels/playlists, supported YouTube Music collections, and Bilibili spaces/collections
- Rename, pin, reorder and delete sources
- Duplicate URL detection
- Source browsing with Configure / Queue / Open / Copy actions
- Lightweight metadata cache with stale-cache fallback
- Remembers the last opened source

## ✦ Reliability & UI Polish

- Configure from Kirin Search and Saved Sources now settles on Home before opening the shared Configure sheet
- External-link actions fail safely with a user-visible message instead of throwing through the UI
- New Search, Saved Sources and Download Center content is centered and width-limited on larger screens while keeping full phone support
- Empty Download Center messaging now distinguishes a truly empty history from filters with no matches

## ✦ Engine Behavior Preserved

- Aria2 remains limited to direct HTTP/HTTPS/FTP downloads
- DASH/HLS remains native yt-dlp
- Bilibili speed mode and native fallback remain site-specific
- Explicit format / FFmpeg merge behavior remains unchanged
- Gallery DL stays isolated from yt-dlp core

## ✦ Release Preparation

- Version: `3.1.2`
- Android base version code: `301020400`
- Package ID remains `com.kirin.downloader`
- Universal ABI coverage remains unchanged
