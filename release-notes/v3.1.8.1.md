# KirinDL v3.1.8.1

### Download Center history cleanup hotfix

This hotfix focuses on making **Clear Completed** consistent across the unified Download Center and Gallery DL history.

## ✦ Fixes

- Fixed **Download Center → ⋮ → Clear Completed** only clearing completed yt-dlp / Media history while completed Gallery DL entries remained visible.
- **Clear Completed** now removes completed Media history.
- **Clear Completed** now also removes completed Gallery DL queue entries.
- **Clear Completed** now also removes successful/completed Gallery DL history records.
- Failed Gallery DL history is preserved.
- Pending, running, paused, and failed Gallery queue entries are preserved.
- Downloaded files are not deleted; this action only clears completed activity/history records.
- Updated the confirmation message so it clearly describes both Media and Gallery DL cleanup.

## ✦ Global Feed & Kirin Search

- Added page navigation to Global Feed source contents so large channels, playlists, collections, feeds, and other supported source types can be browsed page by page instead of appearing as one long list.
- Added page navigation to Kirin Search results.
- Moved Global Feed search into the top app bar beside the Add Source action.
- Removed the duplicate **Add Source** button from the blue Global Feed information card while keeping its information text.
- Restyled Global Feed source counts as compact count badges.
- Added an explicit **Play** action to Media results in Kirin Search and Global Feed.

## ✦ Gallery DL Preview

- Added a large image preview directly below the Gallery DL **Paste / Check** controls when the extractor check returns a thumbnail.
- Kept the existing extractor information panel and Gallery DL validation flow unchanged.

## ✦ yt-dlp Progress Experiment

- The temporary **Video / Audio / Fragment / Merge / Processing** progress-stage experiment was removed after testing showed the download error returned in that build.
- The Download Center is back to the previously working progress/status presentation.
- Core downloader files remain on the known-good devpatch11 implementation.

## ✦ Scope

- Unified Download Center
- Gallery DL queue
- Gallery DL history

## ✦ Verification

- Source fix prepared for the next KirinDL hotfix build.
- APK/build verification will be recorded after the corresponding test build completes.
