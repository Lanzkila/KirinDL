# KirinDL v3.1.1

### Smarter downloads • richer Gallery DL • better control

KirinDL v3.1.1 is a major refinement release focused on download speed, format control, Gallery DL workflow, queue management, engine health, and UI customization.

## ✦ Highlights

- New **Bilibili Speed Mode** with Auto, Balanced, Fast, and Custom profiles
- Bilibili-specific fragmented download tuning with safer Aria2 handling
- Automatic **Aria2 → native yt-dlp fallback** for supported Bilibili failures
- Expanded **audio bitrate, codec, conversion, and cover artwork** controls
- Expanded **video codec, container, resolution, and yt-dlp format profiles**
- New **Smart Download Profiles** with custom slots and per-site memory
- New Home quick-profile selector and clearer Media / Gallery DL sections
- Download Queue search, filters, stats, bulk controls, and richer task details
- Gallery DL queue/history search, stats, media filters, and per-site behavior
- Engine Health overview for yt-dlp, gallery-dl, FFmpeg, Aria2, and Python bridge
- Storage Manager and safer temporary-file cleanup
- Expanded Look & Feel with separate body and button/accent color choices
- Automatic engine updates promoted while manual update controls remain available

## ✦ Bilibili & Network

Bilibili now has dedicated transfer profiles instead of relying only on global settings. Auto uses a practical fragmented-download profile, while Balanced, Fast, and Custom modes give more control. Direct HTTP/HTTPS downloads can continue using Aria2 while fragmented DASH/HLS transfers stay with yt-dlp's native fragment handling.

If the external downloader fails on a supported Bilibili task, KirinDL can retry the same task with native yt-dlp without creating a duplicate download.

## ✦ Format & Media Controls

Audio controls now include more bitrate choices, codec preferences, conversion formats, and thumbnail/cover behavior. Video controls now include additional resolution choices, H.264, VP9, AV1 and HEVC preferences, plus MP4, WebM and MKV output options.

Additional yt-dlp sorting profiles include high-FPS, HDR, SDR compatibility, low-bandwidth, quality, compatibility, AV1, VP9 and smaller-file presets.

## ✦ Smart Profiles

Smart Download Profiles provide quick reusable combinations for common download goals, including custom profile slots. KirinDL can also remember the selected profile for supported sites such as YouTube, Bilibili, TikTok, Instagram, X/Twitter, Facebook, Reddit and SoundCloud.

## ✦ Download Queue

The Download Queue now includes improved search and filtering, overview counters, clearer transfer phases, speed/ETA details, and bulk actions including Pause All, Resume All, Retry Failed, and Clear Completed.

Task details provide clearer information about the selected format, transfer state, engine, output, and related download configuration.

## ✦ Gallery DL

Gallery DL receives a more complete queue and history workflow with search, statistics, media filters, per-site behavior, retry/cleanup actions, richer diagnostics, and remembered UI state. The configurable Gallery output root remains organized under site/gallery folders.

## ✦ Engine & Storage

The Engine Update Center now emphasizes automatic updates while keeping manual checks available. Engine Health makes it easier to verify yt-dlp, gallery-dl, FFmpeg, Aria2, and the Python bridge from one place.

Storage tools can inspect KirinDL storage usage and clean temporary download data without deleting completed media files.

## ✦ Look & Feel

Theme customization has been expanded with additional color presets and separate choices for the app body and buttons/accent. Existing preset indexes remain compatible with previous KirinDL settings.
