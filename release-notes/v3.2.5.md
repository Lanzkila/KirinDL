# KirinDL v3.2.5

Prepared · 17 November 2026

This release consolidates Instagram and Telegram URL handling around KirinDL's existing download engines. It also improves Gallery-DL's Instagram cookie handling and recovery from Instagram API redirects.

## ✦ Highlights

- Route Instagram profile, post and Reel URLs submitted from Home into the existing Gallery-DL workflow. Gallery-DL now handles URL inspection, extractor preflight and downloads for supported Instagram URLs. ([5359b28](https://github.com/Lanzkila/KirinDL/commit/5359b289e4fb377aac61d4d5517ed02516083cbc))
- Send Telegram public video-post URLs through the standard yt-dlp download flow instead of a separate KirinDL Telegram engine. Actual extraction remains limited to URL and media types supported by the bundled yt-dlp runtime. ([5359b28](https://github.com/Lanzkila/KirinDL/commit/5359b289e4fb377aac61d4d5517ed02516083cbc))

## ✦ Changes

- Disable the bundled Instaloader dependency and its profile-preview/selection flow; retain the old implementation as commented source for reference. ([5359b28](https://github.com/Lanzkila/KirinDL/commit/5359b289e4fb377aac61d4d5517ed02516083cbc))
- Disable the standalone Telegram Kotlin/Python preview and download implementation; Telegram links use the existing yt-dlp path instead. ([5359b28](https://github.com/Lanzkila/KirinDL/commit/5359b289e4fb377aac61d4d5517ed02516083cbc))
- Keep Gallery-DL and yt-dlp as separate engine paths. Gallery-DL remains responsible for supported Instagram extraction; yt-dlp remains responsible for Telegram URLs it can extract. ([5359b28](https://github.com/Lanzkila/KirinDL/commit/5359b289e4fb377aac61d4d5517ed02516083cbc))
- Preserve **Settings → Network → Cookies**, the cookie-profile page and their navigation unchanged.

## ✦ Instagram Cookie and Extraction Fixes

- Load the configured Gallery-DL cookies file for extractor operations.
- Detect a usable, unexpired Instagram `sessionid` cookie without exposing the cookie value.
- Persist cookie updates exported by Gallery-DL from its private job copy, keeping a backup while replacing the imported cookie file.
- Classify an Instagram API redirect to the home page separately from a missing or expired login, so the error message does not incorrectly blame the user's cookies.
- When that redirect occurs and the installed Gallery-DL engine is behind the current Codeberg master, update the engine and retry the job once. ([5359b28](https://github.com/Lanzkila/KirinDL/commit/5359b289e4fb377aac61d4d5517ed02516083cbc))

## ✦ Compatibility Notes

- Instagram extraction depends on Gallery-DL's current Instagram extractor and a usable session cookie when Instagram requires authentication. Instagram-side rate limits, challenges or account restrictions can still prevent extraction.
- Telegram support is not a full Telegram client. Private/invite-only channels, authenticated account history and media not exposed through yt-dlp's extractors are not added by this release.
- The former Instaloader preview and dedicated Telegram preview/download screens are disabled; their previous source is retained as comments.
- The **Settings → Network → Cookies** UI and cookie-profile navigation are unchanged.
