# KirinDL v3.2.1

Latest · 11 November 2026

## More Tools organization

- Split More Tools into two expandable categories: Video Tools and Gallery Tools.
- Group video, audio and general media utilities under Video Tools.
- Keep GalleryDL and Manga Converter together under Gallery Tools so gallery-related actions are easier to identify.
- Both categories can be expanded or collapsed independently. Existing tool actions and navigation are preserved.

## Smart Download Profiles

- Add Audio Original, Audio Balanced (M4A/AAC at 192 Kbps), and Audio Lossless (FLAC export) alongside the existing Audio HQ and Audio Data Saver profiles.
- Organize the profile picker into General, Video profiles, Audio profiles, and Custom slots.
- Make audio bitrate presets from 32 to 320 Kbps map to yt-dlp's audio format sorter.
- Complete audio extraction conversion mapping for MP3, M4A, Opus, FLAC, WAV, Vorbis, AAC, and ALAC. FLAC export does not restore quality lost in a lossy source.

## Kirin Search

- Fix the result-card action row so Download, Queue and Play have allocated space and the Play label stays on one line.
- Give Play the same outlined box style as Queue for a consistent button layout.
- Move the More actions menu alongside the result information to avoid crowding the main action buttons.

## Validation

The changes are committed to the main branch and the repository's automatic changelog workflow has succeeded. The Android APK build and on-device interaction have not yet been verified for this version.
