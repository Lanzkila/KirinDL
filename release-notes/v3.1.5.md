# KirinDL v3.1.5

### Global Feed • Kirin Search • media input fixes • branding cleanup

KirinDL v3.1.5 promotes the latest tested DevPatch work into the stable release channel.

## ✦ Highlights

- Improved Global Feed compatibility with yt-dlp and gallery-dl collection sources
- Improved gallery/feed thumbnails and collection preview handling
- Reworked Kirin Search into a simpler YouTube + Bilibili discovery flow
- Merged the separate YT Music source into normal YouTube search
- Topic music can be searched directly with `artist or song name + topic`
- Kept Original audio as a YouTube search filter
- Improved Home media URL input and paste handling
- Removed the duplicate Gallery DL URL slot from Home while keeping Gallery DL in Quick Tools
- Improved Download Center integration for media and Gallery DL jobs
- Standardized remaining KirinDownloader branding to KirinDL
- Improved Global Feed action/menu layout on mobile

## ✦ Kirin Search

Kirin Search now exposes YouTube and Bilibili as the main search sources. The previous separate YT Music source has been removed.

For YouTube Topic music, search using the artist or song name together with `topic`.

Existing saved UI state that referenced YT Music falls back to YouTube.

## ✦ Global Feed

Global Feed now handles more yt-dlp and gallery-dl collection-style outputs, including gallery-dl extractors that emit queued child entries instead of direct media URLs.

Thumbnail handling and card fallback behavior have also been improved for collection and gallery sources.

## ✦ Home & Input

The duplicate Gallery DL input block has been removed from Home. Gallery DL remains available through Quick Tools and Global Feed.

Media URL input handling has been simplified so the keyboard clipboard and KirinDL paste button remain the main paste paths.

## ✦ Branding

Remaining visible and source-level KirinDownloader naming has been standardized to KirinDL where appropriate.
