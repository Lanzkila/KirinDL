# KirinDL v3.1.9.1

### Media card progress and multi-architecture Stable release

KirinDL v3.1.9.1 is a Stable revision on top of v3.1.9, focused on the Download Center card status display and release packaging.

## ✦ Media card progress

- Reworked the active Media card status badge so it no longer stays on a generic **Downloading** label.
- The badge now follows the current transfer phase and percentage, including:
  - **Video**
  - **Audio**
  - **Fragment**
  - **Processing**
  - **Merge**
  - **Moving**
  - **Paused**
- Running tasks show the active phase together with the current percentage when available.
- The phase display uses the existing live `Task.DownloadState` and yt-dlp progress text; download execution logic is unchanged.

## ✦ Temporary path display

- Replaced the separate progress area below Media cards with the task's actual temporary folder path.
- Active and paused tasks can now show the current KirinDL temp location under the card.
- The displayed path follows the existing KirinDL temporary download directory used by the downloader.
- Completed and ordinary queued items do not show the temporary path.

## ✦ Stable release packages

Stable releases now publish the same architecture choices available from the build:

- Universal
- arm64-v8a
- armeabi-v7a
- x86
- x86_64
- `SHA256SUMS.txt`

Every APK is checked for the KirinDL package identity, release version, and signature before publishing.

## ✦ README

- Shortened the project README and removed repeated or outdated sections while keeping features, engine updates, releases, build instructions, credits, and license information.
