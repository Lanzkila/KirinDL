# KirinDL v3.2.3.3

Prepared · 16 November 2026

## Instagram Profile Preview

- Add an isolated KirinDL Instaloader adapter under `app/src/main/python/kirindl_instaloader/`.
- Detect HTTPS Instagram profile links submitted from Home and open them in Gallery DL.
- Preview up to 36 recent posts from public profiles.
- Add post selection controls for **Select shown**, **Clear**, and **Queue selected**.
- Send selected canonical post links to the existing GalleryDL queue; GalleryDL remains responsible for downloading the media.
- Fall back to the normal GalleryDL extractor inspection when Instaloader preview is unavailable.

## Compatibility Notes

- Instaloader preview is public-profile only and does not log in or reuse GalleryDL cookies.
- Private profiles, Stories, and Highlights are not part of this integration.
- The existing GalleryDL engine is still required for actual downloads.
