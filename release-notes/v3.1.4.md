# KirinDL v3.1.4

### Downloader controls • Gallery DL polish • adaptive Bilibili • cleaner Pre-Release testing

KirinDL v3.1.4 continues the v3.1.3 polish cycle with stronger download controls, clearer Gallery DL progress and appearance settings, adaptive Bilibili transfer tuning, and a safer side-by-side Pre-Release testing flow.

## ✦ Highlights

- Added queue actions for **Pause All**, **Resume All**, **Retry Failed**, **Clear Completed**, and **Clear Queue**
- Added queue sorting by **Newest**, **Oldest**, **Name**, and **Status**
- Added long-press paste support to the URL input field
- Added **MOV**, **AVI**, and **FLV** video container choices
- Added advanced yt-dlp controls for **Live from start**, **Split HLS discontinuities**, **Write all thumbnails**, and custom **Extractor args**
- Added clearer Gallery DL download progress with item count, stage text, and progress indicator
- Moved **Gallery DL appearance** into **Look & feel** and replaced the long theme list with a compact dropdown
- Improved Search details readability and text cleanup
- Improved Bilibili download recovery with adaptive fragment tuning and stronger retry handling
- Added a dedicated **Kirin Pre-Release** build that can be installed beside Stable

## ✦ Download Center & Queue

The Download Center queue menu now includes bulk controls for pausing active tasks, resuming paused tasks, retrying failed tasks, clearing completed items, and clearing non-running queue entries.

Queue ordering can now be changed between Newest, Oldest, Name, and Status without changing the underlying download tasks.

The Android system Back action also closes the navigation drawer first when the drawer is open, making navigation more predictable.

## ✦ Download Input & Format Controls

The URL input field now supports long-press paste from the clipboard for faster manual downloads.

Video container options have been expanded with MOV, AVI, and FLV alongside the existing automatic, MP4, WebM, and MKV choices.

Advanced download settings now expose additional yt-dlp controls:

- **Live from start** for supported live streams
- **Split HLS discontinuities** for compatible HLS downloads
- **Write all thumbnails** to save every available thumbnail variant
- **Extractor args** for site-specific yt-dlp extractor parameters

## ✦ Gallery DL

Gallery DL now shows more useful progress while a job is running, including the current stage, completed item count, estimated total when available, percentage, and a linear progress indicator.

Gallery appearance has been removed from Engine Update Center and placed under **Look & feel**, where the previous long list of theme choices is now presented as a compact dropdown. Existing Gallery DL theme choices and saved preference behavior remain available.

## ✦ Search Polish

The Search details dialog has been refined with larger, clearer text, improved spacing, and cleanup for malformed escaped line breaks in result metadata.

Download, Open, and Close actions remain available from the same details flow.

## ✦ Bilibili Reliability

Bilibili Auto mode now adapts concurrent fragments using the average speed from the previous successful Bilibili transfer. Slower routes can use more parallel fragments, while already-fast routes reduce unnecessary connection pressure.

Bilibili fragmented transfers also receive stronger retry handling and fragment recovery without changing connection behavior for unrelated sites.

A compile hotfix corrects storage of the remembered Bilibili average-speed value using the long-value preference helpers.

## ✦ Kirin Pre-Release

Kirin Pre-Release is now a separate Android install from Stable:

- Stable package: `com.kirin.downloader`
- Pre-Release package: `com.kirin.downloader.prerelease`
- Pre-Release app label: **Kirin Pre-Release**

This allows Stable and Pre-Release to stay installed on the same phone with separate app data while new DevPatch builds are tested.

The Stable release flow remains separate and continues to use `.github/workflows/android.yml`.
