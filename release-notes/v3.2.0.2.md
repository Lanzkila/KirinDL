# KirinDL v3.2.0.2

### Pre-release testing build

KirinDL v3.2.0.2 is the next testing build after v3.2.0. It can be installed **directly over v3.2.0**; no intermediate v3.2.0.1 installation is required.

> **Testing note:** v3.2.0 remains the recommended Stable release while v3.2.0.2 is being tested. If this build causes a device- or site-specific problem, return to v3.2.0.

## ✦ App update checker

- Added full four-part version comparison for builds such as `3.2.0.2`.
- Stable users ignore GitHub Pre-release builds.
- Pre-release testers can see both Stable and Pre-release builds and receive whichever valid KirinDL version is newer.
- Automatic checks now remember the installed KirinDL version and selected update channel.
- Installing a different KirinDL version forces a fresh update check instead of inheriting the previous build's cooldown.
- Switching Stable / Pre-release channel forces a fresh check even if the normal timer has not expired.
- Failed GitHub/network checks are no longer recorded as a successful "last checked" state.
- Automatic checks use a one-day cooldown only when the installed version and selected channel are unchanged.

## ✦ Update download and install flow

- In-app updates use Android Download Manager.
- KirinDL remembers the app-update Download Manager job.
- When the APK finishes downloading, KirinDL hands it to Android's package installer.
- If **Install unknown apps** permission is required, KirinDL opens the Android permission page and resumes the installer flow afterward.
- An **Update ready** notification is posted as a fallback on Android versions that block background activity launches.
- A release signed with the same KirinDL key updates/overwrites the installed app instead of creating a second installation.
- Android still requires the normal package-install confirmation.

## ✦ Media progress

- Fixed Media progress occasionally moving backward, for example `22% → 21% → 22%`, from slightly out-of-order yt-dlp DASH/fragment callbacks.
- Progress is monotonic within one transfer stream.
- A real new stream such as Video → Audio can still reset normally.
- Video, Audio, Fragment, Merge, Processing and Moving remain separate transfer phases.
- Compose progress refresh is reduced from 200 ms to 100 ms for a more responsive badge.
- Notification updates remain throttled separately to avoid unnecessary Android IPC load.

## ✦ Subtitle downloads

- Separated **Original / manual subtitles** from **Auto-generated subtitles** so each source can be enabled independently.
- The main **Download subtitles** switch now gates subtitle probing and download options consistently.
- Added subtitle language modes: **Original**, **Selected**, and **All**.
- **Original** uses site/uploader subtitle tracks and original auto-caption variants when available, while excluding YouTube translated-caption variants.
- **Selected** preserves the existing yt-dlp language filter, including existing KirinDL values such as `en.*,.*-orig`.
- **All** requests all available subtitle languages except live chat.
- Auto-translated subtitles are disabled while Original language mode is selected to avoid contradictory settings.
- Old queued tasks remain compatible because the new subtitle preference fields have safe defaults.
- Fixed the Subtitle dialog's yt-dlp documentation button so it opens subtitle options instead of sorting-format documentation.

## ✦ Engine Update Center

- Added a collapsible **Show / Hide** runtime section directly after the Gallery DL engine card.
- Added dedicated runtime slots for **Aria2**, **FFmpeg** and **Python**.
- Aria2 shows its current Enabled / Disabled state and configured direct connections.
- FFmpeg and Python show their bundled runtime versions/status.
- Bundled runtime slots clearly state that they are updated together with the KirinDL app instead of pretending to support independent in-app updates.

## ✦ Gallery DL appearance

- Added a **Custom** color tile beside **Lime** in the existing Gallery DL appearance popup.
- All existing Gallery DL theme presets remain unchanged.
- Custom accepts `#RRGGBB` or `#AARRGGBB` and shows a live preview before saving.
- The custom color changes only the Gallery DL accent; background and text continue to follow the active KirinDL theme.

## ✦ Release notes popup

- Cleaner heading and list spacing.
- Duplicate version headings are suppressed.
- Blockquotes render as highlighted notes.
- Nested lists and code blocks are formatted more cleanly.
- Four-part KirinDL versions display correctly.

## ✦ More Tools expansion

Added five new utilities to the existing **More Tools** grid:

- **Subtitle Downloader**
  - Fetches available manual/original and auto-generated subtitle languages.
  - Downloads subtitle tracks without downloading the video.
  - Supports Original, SRT, VTT, ASS and LRC output.
  - Saves subtitle-only output under `Downloads/KirinDL/Subtitles`.

- **Playlist / Channel Extractor**
  - Extracts flat playlist/channel entries through yt-dlp.
  - Supports Select All / None and per-entry selection.
  - Selected links can be copied or queued directly with the current KirinDL download preferences.

- **Media Inspector**
  - Opens local audio/video files with Android MediaExtractor / MediaMetadataRetriever.
  - Shows duration, size, resolution, bitrate and per-track codec/details.

- **Metadata Editor**
  - Edits title, artist, album, year and genre with bundled FFmpeg.
  - Optional removal of existing metadata before applying new fields.
  - Uses stream-copy and leaves the original media untouched.
  - Edited copies are saved under `Downloads/KirinDL/Metadata Editor`.

- **Chapter / Clip Maker**
  - Reads embedded FFmetadata chapters when available.
  - Tapping a chapter fills its exact start/end range automatically.
  - Manual start/end clipping remains available when no chapters exist.
  - Uses FFmpeg stream-copy for fast clipping without re-encoding.
  - Clips are saved under `Downloads/KirinDL/Clips`.

The five utilities use the same embedded More Tools navigation style as the existing Media/Manga converters, so Back returns to the More Tools grid without adding extra top-level routes.
