# KirinDL v3.2.0.6

### Pre-release — Android app updates

This build uses the KirinDL **v3.2.0.3** application as its base, with targeted startup and crash-diagnostic improvements. Tested startup now opens normally on the previously affected device.

## Startup crash fixes

- Install the exception handler **before** MMKV, Koin and app-update initialization, so early Java errors can be captured.
- Retry MMKV initialization on transient failures instead of immediately terminating startup.
- Make non-essential app-update state migration, dynamic color setup and notification-channel setup non-fatal during startup.
- Preserve existing app settings and download data; no automatic data reset.

## Crash diagnostics

- Save the last captured crash report privately on the device.
- Record the last startup stage and preserve a diagnostic hint if a previous launch stopped before startup completed.
- Add **Settings → Troubleshooting → Copy Last Crash Report** so the diagnostic text can be copied after reopening the app.
- Continue logging engine startup failures without stopping the entire app.

## Settings → About

- Keep the **Tools** card for accessing More Tools.
- Keep **Stable** and **Pre-release** cards for release-note popups.
- Remove other About cards from the About screen.
