# KirinDL v3.2.3.2

Prepared · 16 November 2026

## App Update

- Restore the original built-in automatic update checker controlled by **About → App Update**.
- Keep the automatic update preference enabled by default, while allowing users to turn it off from About.
- Resume the built-in update check when the app starts, respecting the existing network and update-preference checks.
- Keep the separate Morphe Home update popup disabled.
- Keep the additional standalone KirinDL startup popup disabled.
- Preserve manual update checking and the existing installation flow in **About → App Update**.
- Keep update notifications governed by their separate notification preference.

## Notes

- This is a new release note for **v3.2.3.2**.
- The already-published **v3.2.3.1** release note is retained unchanged.
- App version metadata will be updated separately when preparing the v3.2.3.2 build.
