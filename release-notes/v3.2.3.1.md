# KirinDL v3.2.3.1

Prepared · 15 November 2026

### Release summary

Restore the built-in automatic app-update check while keeping the additional KirinDL update popups disabled.

---

## ✦ App Update

- Temporarily disable the Morphe Home update popup.
- Temporarily disable the standalone startup update popup.
- Re-enable the built-in automatic update checker through the existing **About → App Update** preference (enabled by default).
- Keep the Morphe Home popup and standalone KirinDL startup popup disabled.
- Keep manual checking and installation available in **About → App Update**; automatic update notifications remain controlled by their separate notification switch.

## ✦ Repository Maintenance

- Remove the temporary pre-publish test-only workflow.
- Leave the official **KirinDL Release** workflow unchanged.

## ✦ Install / Update Notes

- Version name: `3.2.3.1`
- Android version code: `302030410`
- Package ID remains `com.kirin.downloader`.
