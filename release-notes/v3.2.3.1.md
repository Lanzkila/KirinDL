# KirinDL v3.2.3.1

Prepared · 15 November 2026

## App Update Channel Detection

- Match the update-channel selection behavior used by YTDLnis.
- In Pre-release mode, prefer a Stable release when it is newer than the installed app.
- Continue offering newer Pre-release builds while the latest Stable release is older than the installed app.
- In Stable mode, ignore Pre-release releases.
- Ensure the startup Updates popup receives results from the shared automatic update check.
- Preserve the separate **About → App Update** entry point.

## Regression Coverage

- Cover Stable promotion becoming available to a Pre-release tester.
- Cover continuing Pre-release testing while Stable is not yet an upgrade.
- Include app update channel-selection tests in the Release workflow.
