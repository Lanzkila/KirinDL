# KirinDL v3.1.6

### Media Converter • Manga Converter • independent output paths • automatic patch releases

KirinDL v3.1.6 expands More Tools with two local conversion utilities, adds dedicated output-directory controls, improves automatic patch release workflows, and now publishes separate **Universal** and **ARM64** APK variants for both Stable and Pre-Release builds.

## ✦ Highlights

- Added a new **Media Converter** under More Tools
- Added a new **Manga Converter** under More Tools
- Added independent output-directory settings for both converters
- Added batch conversion and progress handling
- Reused KirinDL's bundled FFmpeg runtime for local media conversion
- Added automatic next-patch generation for Kirin Pre-Release builds
- Added automatic next-patch generation for Stable release builds
- Added separate **Universal** and **ARM64** APK release variants
- Pre-Release remains installable beside Stable with its separate package ID

## ✦ Media Converter

Media Converter works with local video and audio files and includes video-to-video, video-to-audio, and audio-to-audio conversion.

Supported controls include output container, video/audio codec, video/audio bitrate, resolution, FPS, CRF quality, sample rate, channel count, trim start/end, metadata, subtitles, remove-audio mode, fast remux, presets, batch input, conversion progress, and cancellation.

Common output formats include MP4, MKV, WebM, MOV, AVI, FLV, MP3, M4A/AAC, Opus, OGG, FLAC, and WAV where supported by the bundled FFmpeg build.

## ✦ Manga Converter

Manga Converter adds the requested local archive conversion paths:

- ZIP → CBZ
- CBZ → ZIP
- ZIP → PDF
- CBZ → PDF

The converter includes natural page sorting, junk-file filtering, batch conversion, progress display, automatic duplicate-safe output names, and optional `ComicInfo.xml` metadata when creating CBZ files.

## ✦ Converter Output Directories

**Settings → Download Directory** now contains two additional output slots:

- Media Converter output
- Manga Converter output

Default locations are:

```text
Download/KirinDL/Media Converter/
Download/KirinDL/Manga Converter/
```

A custom primary-storage folder can be selected for either converter. The selected path is remembered until it is reset.

## ✦ APK Variants

KirinDL now publishes two APK choices for both Stable and Pre-Release builds.

### ARM64

Recommended for most current Android phones and tablets using `arm64-v8a`.

The ARM64 APK contains only the ARM64 native libraries, so the download is smaller than the Universal build.

### Universal

Use Universal when the device architecture is unknown, when installing on a non-ARM64 device, or when one APK needs to cover all supported KirinDL ABIs.

The Universal APK contains:

- arm64-v8a
- armeabi-v7a
- x86
- x86_64

Because it contains all supported native architectures, the Universal APK is larger.

## ✦ Automatic Pre-Release Patch Trigger

The **Kirin Pre-Release** workflow no longer requires manually entering a DevPatch tag.

Each run looks at the latest published Stable release, targets the next patch version, and automatically assigns the next available DevPatch number. For example, after Stable `v3.1.5`, the first new test build becomes `v3.1.6-devpatch1`, followed by `v3.1.6-devpatch2` and so on.

Pre-Release continues to use:

```text
com.kirin.downloader.prerelease
```

so it can remain installed beside Stable.

Each Pre-Release publishes:

```text
KirinDL-ARM64-Pre-Release.apk
KirinDL-ARM64-Pre-Release.apk.sha256
KirinDL-Universal-Pre-Release.apk
KirinDL-Universal-Pre-Release.apk.sha256
```

## ✦ Automatic Stable Patch Trigger

The **KirinDL Release** workflow resolves the next Stable patch automatically from published Stable releases.

After Stable `v3.1.5`, the next Stable target is `v3.1.6`. After `v3.1.6` is published, the following Stable workflow targets `v3.1.7`.

The workflow stages the generated version and version code only inside the Actions runner before building, verifies the final APK package/version/signature, and uses the matching release-notes file when publishing.
