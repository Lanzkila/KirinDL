# KirinDL v3.2.3

Prepared · 15 November 2026

## Startup Update Popup

- Refresh the automatic update prompt with a compact **Updates** dialog inspired by YTDLnis.
- Show the available KirinDL release as a selectable card instead of opening the full changelog immediately.
- Open the existing release-details dialog only after the update card is selected.
- Add a close button and a Dismiss action that remember the dismissed release, while still allowing a newer release to appear.
- Preserve the existing Auto Update preference, check interval, cached-release fallback, and background APK download behavior.
- Keep **About → App Update** unchanged as an independent manual update entry point.
