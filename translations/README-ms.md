## Ciri-ciri

- Muat turun video dan audio daripada laman yang disokong [yt-dlp](https://github.com/yt-dlp/yt-dlp).
- Muat turun gambar serta galeri menggunakan [gallery-dl](https://github.com/mikf/gallery-dl).
- Sokongan senarai main, muat turun berkelompok, barisan tugas dan sejarah muat turun.
- Sokongan sari kata, metadata, gambar kecil dan SponsorBlock.
- Pemprosesan FFmpeg, integrasi aria2 serta arahan yt-dlp tersuai.
- Pratonton dan semakan extractor gallery-dl, kuki serta konfigurasi JSON.
- Integrasi Gallery DL dengan Global Feed dan Kirin Search.
- Muat turun di latar belakang dengan kemajuan berasingan bagi video, audio, fragmen, penggabungan dan pemprosesan.

## Kemas kini enjin

**yt-dlp** (Stable dan Nightly) serta **gallery-dl** daripada Codeberg boleh dikemas kini tanpa perlu menunggu APK KirinDL baharu.

- [yt-dlp](https://github.com/yt-dlp/yt-dlp/releases)
- [gallery-dl](https://codeberg.org/mikf/gallery-dl/releases)

## Muat turun aplikasi

Dapatkan APK rasmi melalui [KirinDL Releases](https://github.com/Lanzkila/KirinDL/releases). Versi Universal, arm64-v8a, armeabi-v7a, x86 dan x86_64 disediakan bersama semakan SHA-256. Nama pakej: `com.kirin.downloader`.

## Bina daripada kod sumber

Untuk bina versi Debug atau Release daripada kod sumber:

```bash
./gradlew assembleGenericDebug --stacktrace --no-daemon --no-configuration-cache
./gradlew assembleGenericRelease --stacktrace --no-daemon --no-configuration-cache
```

## Nota penting

Sokongan laman web bergantung pada enjin muat turun. Sesetengah laman memerlukan log masuk, kuki atau versi enjin yang lebih baharu. Muat turun hanya kandungan yang kau ada hak untuk simpan.

## Asal-usul dan kredit

KirinDL berasal daripada **Seal → SealPlus → KirinDL** dan menggunakan yt-dlp, gallery-dl, youtubedl-android, aria2 serta FFmpeg. Hak cipta, lesen dan penghargaan projek asal tetap dikekalkan.

- [Seal](https://github.com/JunkFood02/Seal)
- [SealPlus](https://github.com/MaheshTechnicals/Sealplus)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [gallery-dl](https://codeberg.org/mikf/gallery-dl)
- [youtubedl-android](https://github.com/yausername/youtubedl-android)
- [aria2](https://github.com/aria2/aria2)
- [FFmpeg](https://ffmpeg.org/)
